# 💫 Sobre mí

**Transformo datos de planta en información útil para la toma de decisiones.**

Soy Ingeniero Electrónico especializado en **Automatización y Control**, con experiencia en el **diseño, programación y puesta en marcha de sistemas SCADA industriales**. Combino esa base (PLC Modicon M221 y Allen-Bradley CompactLogix, SCADA, **Modbus RTU/TCP**, medidores de energía) con herramientas de análisis de datos para extraer, modelar y visualizar información operativa de procesos y sistemas de instrumentación.

He participado en el comisionamiento de proyectos industriales, en la documentación técnica P&ID y en pruebas FAT/SAT. Hoy estoy desarrollando mis habilidades de análisis de datos para aplicarlas a **indicadores (KPIs) de mantenimiento y operación en entornos industriales**, con el objetivo de que la información de planta apoye mejores decisiones.

### Lo que hago

- 🔧 **Extracción y comunicación de datos industriales:** PLC, redes industriales y protocolos Modbus.
- 🗄️ **Modelado y consultas con SQL;** limpieza y transformación de datos con Python y Power Query.
- 📊 **Dashboards e indicadores operativos** en Power BI.
- 🤖 **Modelos de Machine Learning** con Python aplicados a datos de proceso.
- 📐 **Diseño e ingeniería de detalle** con AutoCAD 2D/3D, instrumentación industrial y electrónica de potencia.

**Herramientas clave:** Python · SQL · Power BI · Power Query · Machine Learning · PLC · SCADA · Modbus · IoT · C++ · MicroPython · AutoCAD

# 🗂️ Portafolio de Proyectos

### 🎙️ Patric-Smart — Identificación de Voz y Rostro con IA en MicroPython
Proyecto de tesis desarrollado sobre la placa **Maixduino (Kendryte K210)**, enfocado en identificación biométrica mediante inteligencia artificial embebida.

- 🔊 Verificación de hablante (speaker verification) con modelo **YOLO v2-MobileNet**
- 📷 Reconocimiento facial mediante cámara integrada en la tarjeta embebida
- 📟 Diseño e implementación de un clasificador de patrones (palabra clave del hablante)
- 🎚️ Procesamiento de señales de audio con FFT (MicroPython)
- 🐍 Desarrollado en **MicroPython** y **Python**, con notebooks Jupyter para el entrenamiento de modelos
